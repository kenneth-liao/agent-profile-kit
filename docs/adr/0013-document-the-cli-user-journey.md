# Document the CLI user journey in one living map

`docs/USER-JOURNEY.md` is the canonical home for user-facing CLI surface behavior: the stages a person moves through, the command that drives each stage, the outcome each stage owes them, and the registered gaps between the two. No existing location owns this fact. `docs/ARCHITECTURE.md` owns structure rather than what a person sees; `docs/guides/workspace.md` is bundled end-user guidance served by `agent-profile-kit guide` and teaches authoring formats, not CLI presentation quality; `docs/adr/` owns settled decisions rather than an open improvement surface; and the issue tracker owns individual units of work rather than the map they are cut from. The map holds the journey and a stable-ID gap register; stages reference gap IDs instead of restating them, and each gap graduates by becoming a tracker issue that cites its ID. Presentation principles recorded there are explicitly proposals until a later ADR accepts them, so the map never doubles as an unreviewed decision record.
