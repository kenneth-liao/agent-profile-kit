# Domain docs

This is a single-context repository.

Before exploring or naming domain concepts, read:

- `CONTEXT.md` at the repository root for canonical vocabulary and cross-cutting invariants.
- Relevant accepted decisions under `docs/adr/`.
- `docs/ARCHITECTURE.md` for current structural facts.

Use the glossary's defined terms rather than introducing synonyms. If work contradicts an accepted ADR, surface the conflict explicitly instead of silently overriding it.
