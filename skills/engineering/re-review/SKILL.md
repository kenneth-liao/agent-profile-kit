---
name: re-review
description: Re-review changes or a PR after issues have been raised during the review process. Performs the re-review to ensure changes completely and correctly address the issues and determines if the PR is ready to merge or needs follow-ups.
user-invocable: false
---

Re-review the PR, reading all new changes and the comments posted by the coding agent. Verify that each issue raised in the review has been completely and correctly addressed by the changes, with no new breaking changes, regressions, or changes in functionality/UX. If you have follow ups for the coding agent to address, post them directly to the comment threads. Otherwise, give a concise summary to the user of your findings and let them know that the PR is ready to merge.
